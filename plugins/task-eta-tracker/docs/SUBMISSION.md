3. Tell me why this task is taking so long and what remains.

## Release notes — 0.1.0

Initial skills-only release. Task ETA Tracker builds an evidence-based forecast from observable completion criteria, three to seven milestones, elapsed time, mandatory verification, blockers, and uncertainty. It reports an optimistic-to-pessimistic range, likely center, and confidence; revises the forecast when evidence changes; distinguishes active work from external waits; and never treats the ETA as permission to weaken acceptance criteria. No MCP server, hosted service, authentication, analytics, or developer-controlled data storage is used.
