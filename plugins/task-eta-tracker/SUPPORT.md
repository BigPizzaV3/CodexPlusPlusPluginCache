# Support

For bugs, forecasting behavior reports, documentation issues, or feature requests, open a [GitHub issue](https://github.com/timyeou1234/task-eta-tracker/issues).

Include the plugin version, Codex surface, a sanitized description of the task, the forecast shown, and what evidence later made the estimate inaccurate. Do not post credentials, private repository contents, customer data, or personal information.

This community project does not provide guaranteed response times or emergency support.
