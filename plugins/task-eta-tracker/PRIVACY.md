# Privacy Policy

Effective date: August 15, 2026

Task ETA Tracker is a static, skills-only Codex plugin. It does not operate a hosted service, require an account, include an MCP server, transmit data to the developer, use analytics, or collect personal information.

The plugin instructs Codex to reason about the active task's milestones, elapsed time, verification work, blockers, and uncertainty. Those operations use the user's existing Codex environment and remain governed by the user's OpenAI account and applicable OpenAI policies. The plugin itself does not create a separate developer-controlled data store.

Task content may include repository details or other information the user has already made available to Codex. The plugin instructs Codex to report only the progress evidence needed for an honest forecast and does not request credentials, secrets, unrelated personal data, or external access.

Questions or privacy requests may be opened through [GitHub support](https://github.com/timyeou1234/task-eta-tracker/issues).
