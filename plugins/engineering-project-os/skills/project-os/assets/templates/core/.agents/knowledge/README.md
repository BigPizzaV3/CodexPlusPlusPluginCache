# Engineering failure knowledge

- `project/failures.json`: confirmed lessons that still depend on this repository or environment.
- `reusable/failures.json`: sanitized, reviewed and user-owned lessons that can be reused across projects.

Candidates and hypotheses belong in the findings register. Add a knowledge entry only after confirming the mechanism. Prepare and approve reusable lessons before transfer, deduplicate by stable ID and retire obsolete advice with its replacement and reason. Nothing uploads or synchronizes in the background.
