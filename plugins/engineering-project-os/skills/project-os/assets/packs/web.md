# Web capability pack

Apply this pack when a browser interface or browser-owned client state is affected.

- Read the existing design system, product copy, routing, state ownership, accessibility and responsive conventions before changing behavior.
- Preserve accepted behavior and repair the reported defect without redesigning adjacent surfaces.
- Verify affected viewport extremes, keyboard navigation, focus, loading, empty, error, reduced-motion and content-growth states.
- Treat confirmed content, request activity, transport completion and visible presentation as distinct states. Do not let unrelated pending work hide an actionable failure.
- Distinguish source inspection, browser automation, screenshots, hosted preview, production and human acceptance. Require only the evidence classes named by the change and its acceptance contract.
