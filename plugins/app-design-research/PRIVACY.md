# Privacy policy

Effective: 2026-09-06. Applies to Hugging App v0.1.5 and earlier App Design Research versions, published by Austin Wise (individual), using the PatchworkMD brand and GitHub account. PatchworkMD is not a separate registered entity.

## What this package does

The skill asks your existing AI host to review references you supply and suggest design changes. Supplied material can include screenshots, interface text, source code, names and other personal information visible in those materials. Processing is for the review you request. Share only material you are entitled to use, and remove private information first.

The package has no maintainer-operated server, analytics endpoint, advertising integration, account system, payment collection, or automatic upload mechanism. It does not intentionally collect credentials. The public Hermes entry point disables website research before browser dispatch. Installing this release does not connect an AppLlama account or authorize website access.

## Who receives data

Your AI application, its configured model provider, and any organization administering that application may process your inputs and outputs under their own settings and policies. Using a locally installed skill does not mean inference is local. The package does not promise zero retention, no model training, or a particular processing region for those providers.

Austin Wise does not receive your review content through this package. If you voluntarily open a GitHub issue or pull request, maintainers and the public can see your GitHub handle and the material you post. That information is used to respond to support requests and maintain the project. Never post confidential material, credentials, or personal screenshots in public issues.

## Retention and controls

The package creates no separate store of review content. Your AI host may retain chats, files, tool results, and logs. Use that application's controls and applicable privacy policy to manage or delete them; uninstalling a skill does not delete host records.

GitHub support posts remain until edited or deleted using available platform controls or removed by a maintainer. There is no automatic project-specific expiry schedule. Closing an issue does not delete it. GitHub may retain other records under its own policy; maintainers cannot guarantee removal of copies, forks, caches, or backups.

You can stop using or uninstall the package and withhold sensitive material. For project questions or removal requests, use [GitHub issues](https://github.com/PatchworkMD/app-design-research/issues) with only a public item URL and minimal details. This project currently offers no confidential support upload channel. For GitHub account or platform privacy requests, use GitHub's privacy channels.

## External policies and changes

[GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) governs GitHub's processing. Consult your AI host's current privacy settings and policy separately. No AppLlama content is retrieved by this release. Future network functionality would require a new review, release, and notice. Changes to this policy will be recorded in repository history and release notes.
