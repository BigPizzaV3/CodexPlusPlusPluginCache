# Project report learnings

This directory is a template for the **consuming project**. Copy it to that project's `docs/report/` when no report-specific documentation exists.

Create focused files such as `legacy-compiler.md`, `shared-subreports.md`, or `form-layout-conventions.md`. Update an existing topic instead of creating duplicate lessons.

Use this structure:

```markdown
# Short pattern name

## Context
- JasperReports/iReport version:
- Affected report or report family:

## Symptom
What failed in compilation, runtime filling, or visual comparison.

## Confirmed cause
The evidence-backed cause. Do not record guesses as rules.

## Validated correction
The smallest correction that worked.

## Verification
Compiler command/result, runtime test, or visual comparison used to confirm it.

## Reuse boundary
Where the lesson applies and where it may not apply.
```

Do not record credentials, personal data, internal company names, private infrastructure, or unrelated business rules. Local project knowledge stays local until the user explicitly asks to promote a reusable rule into the distributed skill.
