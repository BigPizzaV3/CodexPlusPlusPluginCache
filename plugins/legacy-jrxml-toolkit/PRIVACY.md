# Privacy

Jasper JRXML Legacy is a local Agent Skill and a skill-only plugin for Claude Code and Codex. It has no hosted backend, analytics service, telemetry client, advertising SDK, or account system.

The plugin itself does not collect, transmit, or store personal data, source code, report contents, credentials, or usage information.

When the skill asks Claude Code or Codex to inspect local files or run the bundled compiler script, those operations remain subject to the permissions, privacy terms, and configuration of the user's agent environment. The plugin does not send that data to the maintainer.

The bundled PowerShell compiler uses only paths and dependencies explicitly provided by the user from the consuming project. It does not download dependencies automatically.

Questions or suspected privacy issues can be reported through GitHub Issues:

https://github.com/vitorhugo-dotnet/jasper-jrxml-claude-skill/issues
