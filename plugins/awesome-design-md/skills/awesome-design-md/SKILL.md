# Awesome DESIGN.md

Use the bundled design analyses as references for UI work. They are static design studies, not live copies of any website.

## Workflow

1. Read `references/INDEX.md` and identify the closest relevant reference to the user's request.
2. Read only the selected `references/design-md/<name>/DESIGN.md` file unless comparison is useful.
3. Extract reusable design decisions: typography, spacing, hierarchy, layout, component treatment, motion, borders, radii, and visual density.
4. Apply those decisions to the user's actual product, content, accessibility requirements, and technical stack.
5. Do not copy brand text, logos, product claims, or proprietary content unless the user supplied them and explicitly wants them used.
6. If the user asks for a generic style rather than a named reference, choose the closest one and state which design language informed the result.

## Important

Treat the bundled files as reference material. Do not claim that they represent the current live design of the referenced companies or websites.
