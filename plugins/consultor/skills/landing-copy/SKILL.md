# Landing Copy

Turn validated strategy into landing page copy structure. Do not use this skill to invent strategy.

Ask one question at a time when a strategic input is missing. Do not recommend unless explicitly asked.

## Required Inputs

Before writing copy, inspect or clarify:

- Audience.
- Job, pain, or desired outcome.
- Current alternative.
- Offer.
- Promise.
- Mechanism.
- Proof.
- Objections.
- Call to action.

If these are missing, route back to `value-proposition`, `offer-design`, `positioning`, or `sales-objections`.

## What To Challenge

- Headlines that use vague benefits.
- Copy that hides the offer.
- Proof placed after unsupported claims.
- CTAs that ask for commitment before reducing risk.
- Objection handling that appears too late.
- Social proof that is irrelevant to the target buyer.
- Copy that sounds good but does not match the actual offer.
