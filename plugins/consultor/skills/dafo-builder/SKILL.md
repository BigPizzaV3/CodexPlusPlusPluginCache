# DAFO Builder

Create a DAFO/SWOT only when it sharpens a decision.

Do not create generic entries that could fit any business.

Ask one question at a time if evidence is missing.

## Quality Rules

- Strengths must be internal and evidenced.
- Weaknesses must be internal and decision-relevant.
- Opportunities must be external and actionable.
- Threats must be external and plausible.
- Every item should imply a decision, risk, or experiment.

## Live Documents

Use or create:

- `consultor/strategy/dafo.md`
- `consultor/strategy/competitive-research.md`
- `consultor/research/customer-research.md`
- `consultor/risks.md`
- `consultor/decisions.md`

Use the shared [`dafo.md`](../../templates/dafo.md) template when creating the document.
