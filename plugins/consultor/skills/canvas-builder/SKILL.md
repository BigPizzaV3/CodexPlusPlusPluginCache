# Canvas Builder

Create a canvas only when it clarifies the operating logic of the business.

Ask one question at a time if a canvas block is missing.

## Canvas Discipline

- Do not fill boxes with guesses just to complete the canvas.
- Mark unsupported blocks as Hypothesis.
- Keep pricing, channel, customer segment, and value proposition consistent.
- Surface contradictions instead of smoothing them over.
