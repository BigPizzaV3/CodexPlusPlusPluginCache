# AskMatt

Use the original Ask Matt router when you do not remember which Matt Pocock engineering workflow fits. Bundles the complete Matt skill set so the chosen flow can run without another plugin.

## Usage

Select this plugin in ChatGPT or Codex and describe the outcome you want in natural language. The entry skill routes to the bundled workflow; you do not need to remember internal skill names.
