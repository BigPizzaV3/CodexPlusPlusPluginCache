# Changelog

This project follows [Semantic Versioning](VERSIONING.md).

## 2.1.0 - 2026-08-26

- Added strict, published JSON Schemas and consistent machine-readable diagnostics, changes, outputs, losses, hashes, and evidence reports across all three skills.
- Added Mermaid architecture, Gantt, timeline, and Kanban builders targeting the documented 11.16.1 profile; accessibility metadata; hash-guarded, byte-preserving Markdown fence edits; and safe structural SVG/HTML previews.
- Added source-preserving Modelica package edits, a comment/string-aware authoring lexer, supported visual-metadata recovery, topology-aware layout and boundary routing, richer standard graphical primitives, structural previews, and an explicit adapter for an already-installed `omc`.
- Added rich Markdown round trips, GraphML and generated-Mermaid imports, FreeMind cross-links, safe stable-ID merge, diff, explicit reorder, duplicate diagnostics, and three deterministic structural mind-map preview layouts.
- Preserved offline, hosting-free, telemetry-free operation and kept native rendering, compilation, simulation, and third-party application import outside the guaranteed evidence boundary.
- Fixed security audit findings in mind-map Mermaid label emission and Modelica compiler-target validation, and rejected recursive source-to-output Modelica edits.

## 2.0.1 - 2026-08-26

- Fixed Modelica visual generation on Python 3.11 and hardened graphical-annotation replacement, visual geometry, endpoint, metadata, colour, and string validation.
- Unified Mermaid fence parsing and strengthened structured grammar, active-content, size, overwrite, and transactional-rendering checks.
- Applied the canonical mind-map contract after every import and transformation, rejected XML DTD/entity declarations, corrected GraphML edge metadata, and hardened format/merge rollback behavior.
- Replaced the inactive hosted-CI claim with a required local macOS Python 3.11-3.13 matrix plus Python 3.14 forward evidence.
- Hardened the standalone Mermaid and Modelica validators against lexical traversal, direct symlinks, and symlinked input ancestors.
- Restricted release inputs to tracked, non-symlinked source files; added strict archive allowlists, cross-archive runtime equality, typed provenance and software inventories, and complete public-file checksums.
- Expanded release scans to every tracked current-tree file and every extracted archive, removed obsolete tracked distribution artifacts, and separated structural download verification from trust-anchored extracted-skill execution.
- Corrected live Directory status and narrowed claims about Markdown preservation, visual round trips, semantic validation, and optional runtimes.

## 2.0.0 - 2026-08-22

- Added canonical multi-diagram Mermaid documents, structured builders, import, semantic linting, safe repair, and explicit optional local rendering.
- Added canonical visual Modelica projects with deterministic layout, connector placement, routed connections, standard icons and diagrams, import, and repair.
- Added rich portable mind maps with stable IDs, metadata, cross-links, import, merge, extraction, Mermaid and GraphML export, and deterministic loss reports.
- Added matching standalone skill ZIPs alongside the three skills-only app-plugin ZIPs.

## 1.0.0 - 2026-08-21

- Stabilized the public contracts for Mermaid diagrams, portable Modelica projects, and portable mind maps.
- Added reproducible local release gates, deterministic inventories, security guidance, and submission dossiers.

## 0.3.0 - 2026-08-21

- Reduced the collection to three open-format, vendor-neutral plugins.
- Added `modelica-projects` with deterministic package generation and portable static checks.
- Removed proprietary notebook and proprietary Modelica runtime integrations.
- Generalized the diagram and mind-map plugins around portable formats.

Earlier releases were withdrawn because their scope and distribution boundaries no longer match the project.
