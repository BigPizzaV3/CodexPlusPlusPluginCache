# Privacy

PrePilot for Marketing is a skills-only plugin. It does not operate a plugin-owned server, collect analytics, store user prompts, or require a plugin-specific account.

The plugin can instruct ChatGPT or Codex to use tools already available to the user when current information is needed. Any data handling by those tools, ChatGPT, Codex, or connected services is governed by the policies and permissions of those products and services.

Do not place passwords, API keys, private customer data, or regulated personal data into marketing prompts unless the active product and workspace are approved for that data.
