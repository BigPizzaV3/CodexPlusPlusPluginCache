# PrePilot for Marketing

A skills-only ChatGPT/Codex Plugin that packages the free PrePilot marketing experience into one focused marketing toolkit.

## What it covers

The plugin contains 24 focused skills for routing, brand context, customer research, competitive intelligence, positioning, strategy, campaigns, behavioral marketing, offers and pricing, copy, content, social, blogging, SEO, GEO/AEO, paid media, creative testing, CRO, lifecycle email, growth experiments, analytics, launches, MENA localization, and final quality review.

The router chooses the smallest useful workflow for the request. It does not require the user to know which skill to invoke.

## Architecture

- Skills-only. No MCP server is required.
- No external account or API key is required.
- No hidden telemetry.
- No live marketing data is invented. Current platform or market facts should be verified when tools are available.
- Third-party source licenses and notices are preserved.

## Install

Install the release ZIP through the Plugin or Skill upload flow available in ChatGPT or Codex. The ZIP uses `.codex-plugin/plugin.json` at archive root.

## Relationship to PrePilot MCP

This free plugin provides reusable marketing reasoning, creation, review, and planning workflows. PrePilot MCP remains the connected product for account-specific tools, stored client context, external actions, and connected data.
