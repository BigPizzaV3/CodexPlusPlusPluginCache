# Focused mode

Select the smallest set of operations and cross-cutting capabilities needed for
one user-visible outcome. Do not broaden the work merely because adjacent domain
Skills exist.

- Confirm the project seam and success condition.
- Route only selected capability IDs and required handoffs.
- Produce local code and tests only when local writes are authorized.
- Keep external actions disabled unless separately and explicitly authorized;
  this Developer Kit workflow still defaults to no real YCloud calls.
- Report selected, deferred, blocked, and out-of-scope work without constructing
  a 19-, 62-, or 90-row matrix unless the user asks for full-first-wave,
  full-whatsapp-operations, or full-supported-operations coverage.
- Do not create a dashboard or bind a UI framework unless the requested outcome
  needs a UI and the project/user has selected its shape.
