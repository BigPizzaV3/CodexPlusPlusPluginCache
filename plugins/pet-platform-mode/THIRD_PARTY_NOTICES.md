# Third-party assets

The MIT license in this repository covers the original source code and plugin
metadata. It does not automatically grant redistribution rights for artwork,
names, trademarks, or other assets obtained from third parties.

Before publishing a release, the maintainer must document the provenance and
redistribution terms for each file under `assets/`. Replace or remove any asset
whose rights are unclear.

## Caiuto Cub demo pet

The Caiuto Cub character and bundled Caiuto Cub spritesheet were created by
CAIUTO AI using ChatGPT's pet creation workflow from an original character
prompt. They are included as demonstration artwork for this project.

## Codex built-in pets

Windowisp does not bundle or redistribute the Codex, Dewey, Fireball, Hoots,
Rocky, Seedy, Stacky, BSOD, or Null Signal artwork. When available, Windowisp
reads those spritesheets from the user's own locally installed Codex desktop
application and keeps a derived compatibility cache on that same computer.

## Enemy artwork

The Ember Imp, Cinder Moth, Moss Hopper, Shellback Roller, Storm Jelly, and
Gloam Golem artwork and animation strips were created by CAIUTO AI using ChatGPT
from original prompts without third-party character or brand references. They
are included as original gameplay artwork for this project.

## Windowisp interface and gameplay artwork

The bundled icon, blocks, materials, gadgets, hazards, toys, pickups, and
treasure-chest artwork were created by CAIUTO AI using ChatGPT from original
prompts. Only the processed files required by the runtime are included in the
public release archive; prompt sheets, source sheets, test captures, and future
background concepts remain development files.
