# Third-party notes

Memory Keeper V4 is an original skills-only workflow. Its design was informed by general patterns observed in project-memory systems, memory transaction skills, file-organizer skills, and Superpowers-style skill discovery/testing: hierarchical ownership, pre/post persistence checks, conservative file organization, mandatory skill routing, evidence-before-completion, test-first process documentation, and defense in depth.

No third-party skill text is vendored. No third-party runtime service, account, MCP server, or external memory provider is required by Memory Keeper itself.
