# Support

Use [GitHub Issues](https://github.com/actowery/fitness-ledger/issues) for reproducible bugs, documentation problems, and feature requests.

Before opening an issue:

- Search existing issues.
- Include the Fitness Ledger version, the skill used, the prompt or workflow, the expected behavior, and the observed behavior.
- Use synthetic fixture data only.
- Remove names, health records, food logs, photos, Library identifiers, account exports, credentials, tokens, and other personal or secret information.

For suspected security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue. Fitness Ledger does not provide medical support or emergency services.
