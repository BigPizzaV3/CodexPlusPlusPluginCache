# Customer Support

For No AI Slop support, use the public issue tracker for reproducible defects, routing problems, unexpected rewrites, validation errors, packaging defects, documentation corrections, and compatibility issues.

Issue tracker:
https://github.com/imMamdouhaboammar/chatgpt-codex-plugin-autopilot/issues

When reporting a problem, include:

- Plugin name: `no-ai-slop`
- Plugin version
- ChatGPT or Codex surface used
- A minimal reproduction
- Validation output when relevant

Do not include credentials, private repository contents, confidential drafts, or personal data in public support reports.
