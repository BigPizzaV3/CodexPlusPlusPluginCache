# Changelog

All notable changes to Product Support Investigator Community will be documented in this file.

The project uses semantic versioning for published releases.

## [Unreleased]

## [0.1.0] - 2026-09-05

### Added

- Evidence-first Product Support Investigator skill.
- Vendor-independent investigation workflow.
- Observed / Inferred / Unknown evidence separation.
- Timeline, correlation, hypothesis, root-cause, confidence, impact, and escalation frameworks.
- Customer-safe response guidance.
- Tool-independent fallback investigation.
- Investigation playbooks and examples.
- Claude, Codex, agent-skill, and Atlassian Forge/Rovo project surfaces.
- Explicit Community Edition positioning and feature boundary.

### Notes

- Zendesk, Datadog, Jira, GitHub, Grafana, and other integrations are optional evidence sources rather than requirements.
- This release establishes the initial Community Edition baseline.
