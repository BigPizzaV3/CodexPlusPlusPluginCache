# note Workspace｜ROGNALIA

noteを続けるための、自分専用の執筆環境を無料で作れます。

日々のメモや経験を残しながら、次に書くことを考え、記事、タイトル、画像までChatGPTと一緒に仕上げられます。
最初にいくつかの質問へ答えると、使い方や保存先も含めて自分に合う形に整えてくれます。

Codex DesktopやChatGPT Workで、PCのフォルダを読み書きできる環境を使います。AIサービスの利用には、各サービスの契約と利用上限が適用されます。

## どちらを使うか

- **まず一記事を書きたい:** [note Studio mini｜ROGNALIA](https://chatgpt.com/plugins/plugins_6a8ae5578dd08191aff6730618697465)
- **自分専用の継続環境を作りたい:** note Workspace｜ROGNALIA

## はじめ方

note Workspaceプラグインをインストールし、PCのフォルダを読み書きできるCodex DesktopやChatGPT Workで選択してください。次の一文から始められます。

```text
自分専用のnote Workspaceをセットアップして。
分からない点は一緒に決めながら進めたい。
```

あとは、ChatGPTからの質問に答え最後に提案された内容を確認すればセットアップできます。

詳しい手順は[使い方ガイド](GUIDE.md)にあります。

ソースから導入する場合は、[導入方法](INSTALL.md)を参照してください。

## 普段の使い方

セットアップが終わると、普段どこに話しかければよいかをChatGPTが案内します。

- 「今日はこの出来事を書きたい」
- 「このメモを残して」
- 「次は何を書こう？」
- 「この下書きを整えたい」

使う場所に迷った時も、「どこに話しかければいい？」とChatGPTへそのまま聞いてみてください。

## 自分に合う環境へ育てる

最初から完璧に決める必要はありません。
使ってみて不明な点や変えたいことが出たら、ChatGPTにどんどん聞いてみましょう。

担当の分け方、投稿頻度、保存先、文章の好み、画像や振り返りの使い方などはいつでも変えられます。
自分なりのnote環境を一緒に作ってみてください。

noteの公開や予約投稿は自動では行いません。noteへの下書き登録も、完成した記事と画像を確認してOKした場合だけ進みます。
