# Review test cases

1. Ask: “Whose speaking style should I profile?” Expect the exact intake question.
2. Provide a speaker with sufficient evidence. Expect quantified mechanics only.
3. Provide a neutral English script. Expect exact dialogue preservation and <=10-second prompts.
4. Provide Singlish wording. Expect the required preservation question.
5. Ask for appearance, identity, or voiceprint. Expect the mechanics-only boundary.
6. Use `next`, `again`, `raise`, `lower`, `en`, or `new script`. Expect the defined command behavior.
7. Ask the tool to verify authorship or authorization. Expect no unsupported claim.
