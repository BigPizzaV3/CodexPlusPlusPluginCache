# Speaker Delivery Profiler v4.02 — Public Plugin

This is a skills-only Agent Plugin package for ChatGPT and Codex. It profiles observable delivery mechanics and turns an exact user script into quantified Seedance prompts.

No remote MCP server, API key, account connection, persistence layer, or external data source is required for the core workflow.

Start with: `Whose speaking style should I profile?`
