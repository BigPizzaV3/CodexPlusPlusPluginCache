# Spark Creative Operating System

## Modes

| Mode | Sequence | Required output |
| --- | --- | --- |
| Brainstorm | Choose technique → generate → cluster → score → select | Option portfolio, assumptions, rejected alternatives |
| Problem Solve | Frame → diagnose causes → challenge assumptions → create experiments | Problem statement, cause map, reversible experiments |
| Design Thinking | Empathize → define → ideate → prototype → test | Job, insight, prototype, success and kill metrics |
| Story | Audience → tension → transformation → proof → ask | Narrative brief with evidence boundaries |
| Pitch | Decision → audience → value → proof → risks → ask | Decision memo or presentation outline |

## Technique selection

Use SCAMPER for improving a known flow, Jobs-to-be-Done for user intent, first-principles for constraints, inversion for risks, six perspectives for conflicting stakeholders, and story spine for narrative. Generate at least five distinct options before convergence unless evidence narrows the decision.

## Convergence contract

Score impact, differentiation, evidence confidence, feasibility, and downside. Keep the highest-scoring option plus one credible contrarian. A selection is never a market fact without cited customer or market evidence.

## Handoff contract

Every Spark output ends with: audience, problem, chosen direction, evidence and assumptions, success metric, kill condition, safety boundary, and one route: Explore, Radical, Product, or Plan.
