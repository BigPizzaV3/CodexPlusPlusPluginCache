# ForgeMind Portfolio

Inspect the active repository and discover the maximum defensible AI-native product opportunities. For every candidate, state the workflow replaced, 10x outcome, AI core, moat, target user, metric, guardrails, kill condition, rollback, and evidence basis. Treat repository-only inferences as hypotheses. Run `forgemind portfolio discover`, then continue eligible non-conflicting candidates with `forgemind portfolio run`.
