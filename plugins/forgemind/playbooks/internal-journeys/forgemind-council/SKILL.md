# Council

When invoked without user text, load `playbooks/zero-input-defaults.md` and execute **Council** for the most consequential unresolved project decision.

Run `node <plugin-root>/bin/forgemind.mjs council decide --goal "<outcome>" --artifacts workspace --json`. It produces Product, Customer, Technical, Risk, and Contrarian perspectives. Separate facts, assumptions, disagreements, decision, dissent, owner, metric, kill condition, and next action. Do not invent consensus.
