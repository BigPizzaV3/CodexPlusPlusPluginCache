# ForgeMind Growth

Run `forgemind growth`. If the command is unavailable, run `node <installed-plugin-root>/bin/forgemind.mjs growth`. Produce bounded growth experiments from repository and supplied evidence. Never contact customers, change billing, or spend money without an explicit configured adapter and policy.
