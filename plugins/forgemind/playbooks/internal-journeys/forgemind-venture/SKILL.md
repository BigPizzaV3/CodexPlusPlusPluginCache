# Venture

When invoked without user text, load `playbooks/zero-input-defaults.md` and execute **Venture** for the strongest available opportunity. State that the goal was automatically derived.

Run `node <plugin-root>/bin/forgemind.mjs venture run --goal "<outcome>" --artifacts workspace --json`. Build an evidence-labelled venture case: sources, customer problem, competitive alternatives, pricing hypotheses, conservative/base/upside scenarios, sensitivity, required validation, and a Go/No-Go recommendation. Never turn missing sources into market facts.
