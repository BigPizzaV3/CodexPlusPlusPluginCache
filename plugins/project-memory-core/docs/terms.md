# Terms of Use

Effective date: 5 August 2026

## Use of the plugin

Project Memory is provided to help users maintain local Markdown project knowledge. Users are responsible for selecting appropriate storage locations, reviewing proposed file changes, maintaining backups, and complying with organizational policies governing code, conversations, and project data.

When automatic orientation is enabled, Project Memory may add a clearly marked block to the primary code repository's `AGENTS.md` after user approval. Users are responsible for reviewing that repository change before committing or distributing it.

## No external storage service

The plugin does not provide cloud storage, synchronization, backup, or recovery. Users should maintain appropriate independent backups of their vault and optional summaries.

## Sensitive and regulated data

Users must not use Project Memory to store credentials or information they are not authorized to retain. Users are responsible for determining whether their employer, client, or applicable law permits project information to be stored in the selected location.

## Availability and changes

The plugin may change or be discontinued. Features depend on the capabilities and permissions available in the user's Codex environment.
