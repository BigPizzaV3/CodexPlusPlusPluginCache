# MixMatter 3.0.0 — Skills-only update

This package is for the **Upload new version** dialog of the existing Skills-only MixMatter plugin.

It contains four independent Skills:

- `mixmatter-image`
- `mixmatter-sticker`
- `mixmatter-meme`
- `mixmatter-motion`

It intentionally does not contain MCP configuration, Matter Studio widget code, or submission screenshots. The current ZIP update channel accepts Skills only and would exclude those items.

To publish the interactive Matter Studio version, deploy the remote MCP server first and create a separate **With MCP** submission in the OpenAI Platform.
