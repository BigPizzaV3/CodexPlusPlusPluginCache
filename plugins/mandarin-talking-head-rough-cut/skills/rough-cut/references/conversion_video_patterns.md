# 引流与推广口播剪辑

在通用口播规则之上，推广类视频还要同时维护“内容价值、信任建立、合规表达和行动引导”。
只保留卖点会让内容失去可信度，只保留干货又可能无法完成用户设定的转化目标。

## 一、先判断内容类型

常见结构：

1. **短推广**：钩子 → 一个可信场景 → 核心价值 → 合规 CTA。
2. **活动预告**：活动信息或福利条件 → 时间与适用范围 → CTA。
3. **长干货种草**：问题 → 解释 → 适合与不适合的人群 → 轻量导流。
4. **体验或评测**：使用背景 → 观察 → 优缺点和条件 → 建议。

不要套固定秒数。根据当前素材的有效信息量和发布要求确定长度。

## 二、钩子必须来自原素材

可以使用：

- 设问；
- 反常识但有后文支撑的观点；
- 明确场景或痛点；
- 有完整条件的活动信息；
- 后文已经说过的有力原句。

不得制造素材里不存在的结果、稀缺性、权威性或承诺。把后文原句前置时，必须保留它的
限定条件和必要上下文。

## 三、不要误删信任内容

下列内容可能不是直接卖点，但常承担信任功能：

- 用户经历或案例；
- 适用与不适用条件；
- 优点与限制；
- 方法清单和选择标准；
- 可验证的数据或来源；
- 主讲人实际使用背景。

保留这些内容不代表默认保留个人信息。公开发布前，应按用户要求处理案例姓名、未成年人
信息、联系方式、精确地址和其他不必要的识别信息。

## 四、CTA 要准确、克制、可执行

CTA 应说明观众下一步做什么，并与素材里实际提供的渠道和条件一致。删除 CTA 之后的收工
闲聊。不得通过剪辑制造素材里没有的截止时间、库存、赠品或资格。

## 五、合规复查

重点检查：

- 绝对化或排名性用语；
- 无依据的效果承诺；
- 删除限定词后导致含义夸大；
- 数据、资质和案例背书缺少上下文；
- 把场外讨论中的暂定说法误当最终版本。

有现场重录版时留合规版本；没有时只做不改变原意的安全删减，无法处理则标记并让用户确认。

## 六、同一母素材输出多版本

多版本应在叙事策略上有真实差异，而不只是替换字幕或 BGM：

| 维度 | 变化方式 |
|---|---|
| 钩子 | 设问版、场景版、观点版 |
| 信息密度 | 完整论证版、核心要点版、短预告版 |
| 人群 | 面向不同适用条件或关注点 |
| CTA | 轻量了解、明确行动 |

每个版本使用独立的 `timeline_edited`，并分别完成逻辑通读、合规检查、渲染和接口抽听。
某一版本删除的片段不能物理破坏母素材或其他版本的保留集。
