# 口水词 / 磕巴 / 假开头 识别参考（④裁决时对照）

这份是词表和典型形态,给你在 timeline.md 上逐句清理时**对照识别**用。不是脚本、不用打分,看到符合的就按规则删(拿不准就留)。

## A. 语气词 / 口头禅（看语境删大部分、留少量保人味）

**常见词表**（可持续扩充）：
```
嗯、啊、呃、哦、唉、这个、那个、就是说、然后呢、
对吧、你知道吧、怎么说呢、其实呢、就是那个、这样子
```
- **注意歧义**：`这个/那个` 后面紧跟名词时是**实词**（"这个方法"不能删"这个"）→ 保留。
- 同一段连着好几个"然后/就是"→ 删多留一,别删光(删光像机器人念稿)。

### 句首“对”等短词的上下文判定

句首出现“对、然后、那、其实、就是、所以、但是”时，必须在第一遍剪后逐字稿通读中逐个
判断，不得按词表机械处理：

- **有承接功能则留**：确实回应上一句的提问/判断，或承担转折、因果、递进，删掉会改变
  语义关系。
- **无承接功能则删**：上一句已经完整结束，本句是在重新起话；短词后有明显停顿；去掉后
  本句独立完整且与上一句衔接更顺。这类通常是确认状态、找话头、磕巴或口水词。
- 测试方法：分别连读“上一句 + 原句”和“上一句 + 删除短词后的句子”。后者更直接且
  不损失逻辑时删除。
- 例：“作为家长……给孩子吗？对，最近我听了一个名词……”中的“对”并未回答问题，
  且“对”后停顿再另起一句，应删为“作为家长……给孩子吗？最近我听了一个名词……”。

## B. 磕巴重复（同一个意思连说两遍，前一遍是废的）

- 形态：相邻两个短语意思几乎一样、挨得很近 → **保留后一遍,划删前一遍**。
- 例："我觉得吧…我觉得这个事儿" → 删前面的"我觉得吧"。
- ⚠ 别和"同义选优/连接骨架"搞混：如果前一句带着后一句需要的**主语/连接词**,别整句删,只清磕巴留骨架（见 editing_rules 4.5、规则7）。

## C. 假开头 / 说一半重来（NG）

- 形态：一句话没说完就停/改口,后面跟一个意思相近的完整版 → **删没说完的那半截,留完整版**。
- 例："因为这个…嗯…因为孩子的成长是长期的" → 删"因为这个"。
- 信号词："不对""等下""我重说""又讲偏了"——出现这些,前面那段多半作废(见 koubo_logic 五)。
- ASR 可能把口头的“不对”识别成普通“对”。若转写形成无法解释的搭配（如“英语对录播课”），
  不要按正常介词“对”硬读；回听并结合停顿判断是否为自我纠正，把错误起头与纠错词一起删掉。

## D. 停顿

- 纯空白的拖沓、卡壳的尴尬停顿 → 该压该删。
- 斟酌措辞的短停顿、动情处的停顿 → **留**(是真实感/情绪),别当废话删。
