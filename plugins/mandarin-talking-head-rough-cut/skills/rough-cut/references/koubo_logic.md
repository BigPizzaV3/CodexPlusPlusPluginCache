# 中文口播成片的通用逻辑

本页描述从多类中文单人及轻对谈口播中抽象出的剪辑方法。它不是某位创作者的风格复刻，
也不要求成片符合固定时长或删减比例。每次裁决都以当前素材的原意、论证结构和发布目标
为准。

## 一、不要用时长或删减比例倒推内容

- 有效内容多就保留得长，有效内容少就自然更短。
- 只删少量内容可能已经清理完整，删除很多也可能仍漏掉失败 take。
- 时长和删减比例只能作为完成后的统计，不能作为删掉论点、背景、例子或连接骨架的理由。
- 一条成片通常围绕一个清晰主题。原始录制混入多个独立主题时，拆成多条或由用户确认主线。

## 二、找到真正的话头

录制第一句经常是试麦、倒数、对词或找状态。有效话头应当能独立成立，并让后文围绕它展开。
常见形式：

1. **设问**：直接提出观众关心的问题。
2. **观点**：先给一个明确判断，再解释原因。
3. **现象**：从可验证的现象或场景切入。
4. **结果或金句前置**：把后文最有吸引力、且不脱离上下文的原句前置。

金句前置不能改变原句条件，也不能把后文尚未建立的指代一起搬到开头。

## 三、中段必须有推进骨架

常见骨架包括：

- **总—分—总**：提出若干要点，逐项展开，再收束。
- **现象—原因—方法**：描述问题，解释原因，给出行动建议。
- **故事—结论**：用具体经历支持普适观点。
- **问题—比较—选择**：列出选项、适用条件和判断标准。
- **步骤型**：按先后顺序说明操作。

判断一句话是否保留，重点看它是在增加观点、证据、例子、步骤或承接，还是只换一种说法
原地重复。

## 四、结尾要完整收束

常见结尾：

- 回扣开头问题；
- 总结核心观点；
- 给出具体行动；
- 提出开放问题；
- 在推广内容中给出合规、准确的 CTA。

结论说完整后出现的“好了、过了吗、就这样”等收工话删除。不能为了追求有力而把半句
或缺少限定条件的表达放在结尾。

## 五、优先处理的无效内容

1. **前摇与收工**：试麦、倒数、对词、拍摄确认和结束闲聊。
2. **失败 take**：口误、假起头、卡壳、自我否定后重新录制的旧版本。
3. **被明确推翻的表达**：保留更正后的完整版本。
4. **不回收的跑题**：与主线无关且后文没有承担论证功能。
5. **过程话**：主讲人在想“下一句怎么说”，不是在对观众传递内容。
6. **无功能重复**：信息完全被更完整、干净的版本覆盖。

过程话不能只看单句。将前后数句连读，判断说话意图是在面向观众，还是在组织拍摄过程。

## 六、先识别录制形态和说话人

- **单人口播**：主讲人对镜头连续表达。
- **轻对谈/采访式口播**：主讲人与场外人员或嘉宾有问答。

场外人的附和默认不进成片，但其话语可能是剪辑信号：

- “再来一遍、刚才那句不行”表示前一个 take 可能作废；
- “这个词不准确、不合规”表示应优先寻找修正版；
- 一个完整提问若承担开头或承接功能，可经用户确认后保留。

先读取信号，再删除场外话；不能只删提示而把它判废的旧 take 留下。

## 七、推广内容的合规优先级

推广、卖课、卖货或导流内容要检查绝对化、无法验证和无依据承诺。出现问题时：

1. 优先保留现场已经重录的合规版本；
2. 没有重录版时，删除能安全切除的违规词或整个违规句；
3. 删除后必须重新做承接测试；
4. 无法安全处理时停止并让用户确认，不自行改写原声。

## 八、交付前自检

1. 开头是否是真正话头，而非录制过程？
2. 全片是否围绕一个清晰主题？
3. 每段是否推进观点、证据、步骤或案例？
4. 是否留下主讲人讲给自己听的过程话？
5. 是否正确处理场外提示与对应 take？
6. 结尾是否完整收束？
7. 是否因追求时长或删减比例误删独有信息？
8. 成片是否仍像自然的人在表达，而不是被切成机械短句？

全部通过后，才进入精确渲染和接口抽听。
