# 通用视频主题与人物名牌

主题大字和人物名牌属于可选包装。只有用户明确要求，并提供对应文字时才生成；不得从案例、
文件名或历史预设推断姓名、学历、家庭身份、机构头衔或其他背书。

## 一、字体与回退

- 默认使用 `assets/fonts/SourceHanSerifSC-Heavy.otf`。
- 用户可以通过计划文件提供自己有权使用的字体路径。
- 不下载、搜索或复用来源不明的商业字体。
- 指定字体不存在时回退到 Skill 内开源字体或系统中文字体，并在报告中说明。

## 二、计划文件示例

```json
{
  "title_style": "headline-yellow",
  "title_font": "assets/fonts/SourceHanSerifSC-Heavy.otf",
  "topic_lines": ["第一行主题", "第二行主题"],
  "title_slant": 0,
  "speaker_card": {
    "enabled": true,
    "name": "主讲人姓名",
    "lines": ["身份标签一", "身份标签二"],
    "periods": [[0.6, 4.8]]
  }
}
```

姓名和身份必须来自用户当前任务中的明确输入。没有提供时设置
`speaker_card.enabled=false`，不要填入示例文字。

## 三、主题大字

`headline-yellow` 适合明亮或背景复杂的正面口播：

- 顶部居中；
- 金黄大字、轻暗边和适度硬投影；
- 最多两行，每行尽量短；
- 避开人物头顶、眼睛和平台 UI 安全区。

斜体仅用于用户选择的视觉风格；默认 `title_slant=0`。主题大字应概括当前视频，不得引入
主讲人没有表达的夸张结论。

## 四、人物名牌

- 姓名使用一行高辨识文字。
- 身份使用一至两行较小文字。
- 名牌默认只在开场短暂出现；章节转换时可再次出现。
- B-roll、全屏花字或特殊滤镜出现时暂停名牌，避免信息拥挤。
- 不显示未经用户确认的资质、组织关系、学校、职位、家庭状态或未成年人信息。

## 五、交付前检查

使用脚本生成品牌预览帧，确认：

- 文字内容由用户提供且拼写准确；
- 主题、姓名、身份和字幕互不遮挡；
- 所有字体具备当前发布场景所需的使用权；
- 小屏预览仍可读；
- 未把模板占位文字烧入成片。
