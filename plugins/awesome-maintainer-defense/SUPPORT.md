# Support

Use the canonical [GitHub issue tracker](https://github.com/thangldw/awesome-maintainer-defense/issues) for bugs, false positives, installation problems, feature proposals, and documentation corrections. Include the product version, operating system, Python version, exact command, sanitized output, and a minimal reproducer when applicable.

Use the dedicated issue forms when available. Do not publish secrets, private repository material, personal data, or details of an unpatched vulnerability. Report security issues through [Security](SECURITY.md).

Support is community-maintained and has no guaranteed response time. The project cannot administer GitHub organizations, recover accounts, or make decisions for third-party catalog projects.
