# Privacy policy

Last updated: 2026-08-24

Awesome Maintainer Defense is local software. The auditor and packaged skills do not provide a hosted service, create accounts, collect telemetry, or transmit repository content, findings, credentials, or personal data to the project author.

An audit reads files under the repository path selected by the user, local Git metadata, and the configured remote string when needed to identify a repository name. It does not call GitHub or another network service, execute repository code, or inspect live repository settings.

Output stays in the terminal or in a user-selected local file. Users control its storage, disclosure, and deletion. External package managers, Git hosting, ChatGPT, Codex, and linked catalog services have their own privacy terms.

For privacy questions, use the [support issue tracker](https://github.com/thangldw/awesome-maintainer-defense/issues) without including private data.
