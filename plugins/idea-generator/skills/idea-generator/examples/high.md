# High mutation example

## Prompt

`電子工作・夏・食べ物。Mutation Highでアイデア生成`

- Mutation: High / 80
- Parent A: 夏祭りの食べ歩き
- Parent B: 電子工作の分散デバイス
- Constraint: 夏の街歩きと食の体験を中心にする。

## Idea 1 — 街全体が一皿になる回遊食器

複数の屋台と持ち歩く食器が連動し、街を歩くほど一皿の料理が完成する祭り。

### Concept

来場者の食器に付いた小型デバイスが各屋台の受け渡しを記録し、次に必要な味や食感を別の地点の光で示す。屋台は料理の一部を渡し、回遊の軌跡が最後の盛り付けになる。

### Why it is interesting

食べ歩きの「分散」を、分散デバイスで一つの料理へ逆向きに統合する規模転換がある。

### DNA

- Context ← Parent A: 夏祭りを歩いて食べる
- Technology ← Parent B: 複数地点で連携するデバイス
- Scale ← Mutation: 屋台単位から街全体を一皿にする
- Purpose ← Mutation: 移動を料理の工程にする

## Idea 2 — 食べ物が客を選ぶ逆転屋台

屋台側の料理が、街の環境と客の行動に応じて「今食べてほしい人」を選ぶ体験。

### Concept

各屋台のセンサーが気温、混雑、周辺の音を共有し、料理ごとに最も合う時間と場所を判断する。客は端末に届く招待光をたどり、普段なら選ばない一品と出会う。

### Why it is interesting

注文する客が主役という前提を反転し、分散した環境情報を料理の主体性へ変えている。

### DNA

- Setting ← Parent A: 夏祭りの屋台を選んで歩く
- Network ← Parent B: 環境情報を共有する分散デバイス
- Agency ← Mutation: 客が選ぶから料理が招待するへ反転
- Value ← Mutation: 偶然の出会いを祭りの演出にする

## Idea 3 — 気温で縮尺が変わる共同料理

暑さに応じて個人の一口料理が、広場で仕上げる共同料理へ変わる祭りの仕組み。

### Concept

屋台の温度デバイス群が高温を検出すると、各店の小皿メニューは冷やす素材の寄付として配られ、広場の大きな冷製料理へ集まる。涼しい時間帯は逆に、共同皿から個人の持ち歩き料理へ分岐する。

### Why it is interesting

気温という夏の条件を、料理の量と所有の仕方を切り替える制御信号に使い、個人と街の尺度を往復させる。

### DNA

- Social context ← Parent A: 夏祭りで食を共有する
- Sensing ← Parent B: 街に分散した温度デバイス
- Scale ← Mutation: 個人の一口と広場の共同料理を往復
- Ownership ← Mutation: 購入品を共同の完成工程へ移す
