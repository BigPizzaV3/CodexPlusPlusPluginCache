# Medium mutation example

## Prompt

`電子工作・夏・食べ物。Mutation Mediumでアイデア生成`

- Mutation: Medium / 50
- Parent A: 屋台の注文体験
- Parent B: 電子工作のセンサー・光・音
- Constraint: 夏の屋外で、初見の人も参加できること。

## Idea 1 — 音で育つかき氷屋台

客の拍手や会話の熱量で、かき氷のシロップの重なり方が育つ参加型屋台。

### Concept

注文列の音量センサーが一定の盛り上がりを検出すると、屋台の LED が次のシロップ層を示す。客は点灯した色から一つを選び、共同でその時間帯だけの味を完成させる。

### Why it is interesting

屋台の順番待ちを受動的な時間から、音・光・注文が互いに影響する小さな演出へ変える。

### DNA

- Interaction ← Parent A: 屋台で順番に注文する
- Input ← Parent B: 音量センサー
- Output ← Parent B: LED による次の選択提示
- Purpose ← Mutation: 個別注文を共同で味を育てる体験へ

## Idea 2 — 焼き加減共有テーブル

テーブル全体で鉄板料理の焼き加減を見守り、食べ頃を光で共有する席。

### Concept

屋台のテーブルに温度センサーと短い光の帯を置き、各料理の皿を載せる位置ごとに焼き加減を示す。参加者は光がそろったタイミングで取り分け、店員には追加加熱の合図が届く。

### Why it is interesting

注文、調理、受け取りを分ける屋台の流れと、センサー・光の即時性を交配して、食べる判断を客と店員で共有できる。

### DNA

- Service flow ← Parent A: 屋台の注文から受け取り
- Sensing ← Parent B: 温度センサー
- Interaction ← Parent B: 位置ごとの光表示
- Value ← Mutation: 店員の判断をテーブル参加者と共有

## Idea 3 — 夕涼み味覚ルーレット

光と音で回るルーレットが、その夜の注文に小さな味の冒険を足す屋台。

### Concept

客が基本の一品を選んだ後、屋台の光るルーレットを回すと、音に合わせて追加トッピングや食べ方が決まる。センサーは手を近づけたことを検出して開始し、結果は注文札に反映される。

### Why it is interesting

注文の確実さを残しながら、センサー、光、音を使って偶然性を体験として組み込める。

### DNA

- Base choice ← Parent A: 屋台での確定注文
- Trigger ← Parent B: 近接センサー
- Feedback ← Parent B: 光と音のルーレット
- Purpose ← Mutation: 追加注文をゲーム的な味覚探索へ
