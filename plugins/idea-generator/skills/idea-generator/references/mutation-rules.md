# Mutation rules

Treat mutation as continuous intensity, not merely three presets.

| Range | Behavior | Evaluation emphasis |
|---:|---|---|
| 0–34 (Low) | Preserve most parent loci; change one nearby mechanism, context, or feature | Feasibility, usefulness |
| 35–69 (Medium) | Exchange several loci; allow one distant substitution while retaining a clear parent identity | Balanced |
| 70–100 (High) | Use distant contexts, technologies, roles, scales, or inversions; allow initially awkward combinations | Novelty, theme fit |

Interpolate within ranges: 80 is bolder than 70; 100 permits radical transformations but still requires explanation and invariant compliance.

## Mutation selection

Prefer mutations that change causal structure rather than vocabulary. Candidate mutation loci include Target, Purpose, Technology, Context, Value, interaction model, physical form, timing, agency, scale, and ownership.

Never mutate:

- an explicitly locked locus;
- a hard constraint;
- a known conversation fact while presenting it as fact.

If high mutation and strict constraints conflict, mutate unlocked mechanism/context/value more aggressively. Do not silently relax constraints.

For “more realistic”, lower effective mutation and increase feasibility weight. For “ignore feasibility”, set feasibility weight near zero but retain safety, locks, and explicit constraints.
