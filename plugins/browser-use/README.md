# Browser Use — OpenAI-safe package

This package adapts the Browser Use skill suite for OpenAI plugin review. It focuses on host-managed browser automation, website QA, source-code review, remote-browser use when the host already exposes that capability, and hosted-browser architecture guidance.

The public package intentionally excludes bootstrap flows, external runtime installers, payment workflows, instructions for defeating access controls, and instructions that would download or execute code outside the reviewed package.

Upstream project: Browser Use by Gregor Zunic and contributors. The included LICENSE preserves the upstream MIT license and attribution.
