# Browser Use Cloud Reference

This skill is documentation-oriented. It explains Browser Use Cloud concepts and helps design integrations without provisioning infrastructure, authenticating external services, or executing remote code.

## Use it for

- explaining hosted browser session architecture;
- reviewing application-level integration designs;
- discussing lifecycle, observability, error handling, and cleanup;
- drafting neutral interface shapes or pseudocode for a hosted browser abstraction.

## Boundaries

Do not install SDKs, fetch executable code, start remote services, request or move credentials, alter network routing, or provide instructions intended to evade website access controls. If the user needs live Browser Use Cloud execution, use only an approved connector or host capability that is already available; otherwise provide architecture guidance only.
