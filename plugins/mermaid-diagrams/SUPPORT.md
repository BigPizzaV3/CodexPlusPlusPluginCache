# Support

For reproducible bugs, format-compatibility reports, security concerns, or feature requests, open an issue in the [support tracker](https://github.com/theisegoria/chatgpt-skill-plugins/issues). For sensitive security reports, follow [SECURITY.md](SECURITY.md).

Include the plugin name and version, ChatGPT or Codex version, operating system, command or prompt, smallest non-sensitive reproducer, complete error, and whether portable/static validation succeeded.

Do not attach confidential source files, credentials, proprietary models, or private generated artifacts to a public issue.

Support is best-effort with no response-time or availability guarantee. Theisegoria does not operate a hosted service for these plugins and cannot administer third-party accounts, licenses, applications, or platform access.
