# FreeTTS plugin for ChatGPT and Codex

Text to speech in 149 languages with 2,253 voices, through the FreeTTS MCP server at https://mcp.freetts.org/mcp.

- plugin.json: the listing (Agent Plugins format, OpenAI listing under extensions.com.openai.interface).
- mcp.json: the remote MCP server.
- skills/freetts-audio: how to use the tools well.
- assets: logo (512 px) and icon (256 px).

Docs: https://freetts.org/developers/mcp. Source of the server: https://github.com/freetts/mcp.
