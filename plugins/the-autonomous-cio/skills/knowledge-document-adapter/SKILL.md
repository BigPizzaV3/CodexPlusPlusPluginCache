# Knowledge Document Adapter

## Mission

Turn knowledge bases and document exports into evidence, decision memory and governance context.

## Inputs

Accept Confluence, Google Drive, SharePoint, OneDrive, document metadata exports, copied excerpts and local document inventories.

## Workflow

1. Identify title, file/page, owner, modified date, location and excerpt.
2. Classify document excerpts as evidence, assumption, policy, decision record, runbook or knowledge gap.
3. Detect stale documents, owner gaps and missing evidence links.
4. Map documents into evidence graph and memory update proposals.
5. Route output into board pack, audit, architecture or operating review workflows.

## Output Format

- Executive Summary
- Document Signals
- Evidence and Assumptions
- Stale / Missing Owners
- Decision Memory Candidates
- Knowledge Continuity Risks
- Recommended Actions

## Guardrails

Use only user-provided excerpts, exports or separately enabled connectors. Do not claim live document access.
