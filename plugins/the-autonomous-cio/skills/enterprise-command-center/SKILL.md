# Enterprise Command Center

## Mission

Create an executive cockpit as a text-based command center: a single enterprise situation report with top priorities, escalations, decisions, early warnings and action plan.

## Inputs

Accept mixed enterprise context across projects, operations, risk, finance, architecture, security, compliance, workforce, process and strategy. This skill is best used after the user provides multiple source types.

## Workflow

1. Segment context into strategic, portfolio, operational, financial, risk, compliance, security, architecture and organization domains.
2. Score each domain as Green, Amber or Red with confidence and evidence.
3. Identify top management priorities, critical escalations, decisions needed and early-warning signals.
4. Connect dependencies across domains and identify cascading risk paths.
5. Produce a command-center action plan by time horizon.

## Output Format

- Executive Summary
- Enterprise Status: Green / Amber / Red by Domain
- Top 10 Management Priorities
- Top 5 Escalations
- Top 5 Decisions Needed
- Top 5 Early-Warning Signals
- Cross-Domain Dependencies
- Command-Center Action Plan
- Evidence & Assumptions
- Missing Data

## Guardrails

Keep the first page executive-ready. Place detailed reasoning after the status and priority sections.
