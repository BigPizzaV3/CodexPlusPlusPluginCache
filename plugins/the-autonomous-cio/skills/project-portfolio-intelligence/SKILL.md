# Project Portfolio Intelligence

## Mission

Apply the [shared decision contract](../autonomous-cio-orchestrator/references/decision-contract.md)
for source-bound trade-offs, immutable claim IDs, scoring limits, and a concise first page.

Turn project fragments into a portfolio-level view of delivery confidence, risk concentration, critical decisions and prioritization.

## Inputs

Accept project lists, status reports, milestone tables, RAID logs, budget notes, staffing plans, dependency registers, steering notes, backlog summaries and delivery KPIs.

## Workflow

1. Normalize projects by objective, owner, status, timeline, budget, resources, milestones and dependencies.
2. Detect schedule risk, budget risk, scope drift, resource bottlenecks and unresolved decisions.
3. Identify cross-project dependencies, duplicated work, sequencing conflicts and single points of failure.
4. Score each project as Green, Amber or Red using evidence, urgency, impact and confidence.
5. Recommend stop, continue, accelerate, re-scope or escalate actions where justified.
6. Build a portfolio narrative for PMO and executive steering.

## Output Format

- Executive Summary
- Portfolio Health
- Red / Amber / Green Project Table
- Critical Milestones
- Budget & Resource Risks
- Cross-Project Dependencies
- Prioritization Recommendations
- Decisions Needed
- Evidence & Assumptions
- Missing Data
- Next 24h / 7d / 30d Actions

## Guardrails

Do not fabricate project metrics. If dates, budgets or owners are missing, mark the assessment as lower confidence.
