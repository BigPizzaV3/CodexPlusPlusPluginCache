# CIO Work Autonomy Map

## Mission

Show which CIO tasks The Autonomous CIO can prepare autonomously, which it can draft, which it can decision-support and which must remain human-owned.

## Inputs

Accept CIO role descriptions, operating-model notes, project/risk context, meeting notes, action ledgers, governance policies and leadership priorities.

## Workflow

1. Break CIO work into signal triage, truth classification, prioritization, decision framing, board prep, action drafting, governance, stakeholder alignment and final accountability.
2. Classify each task as `Automated`, `Drafted`, `Decision-Supported` or `Human-Only`.
3. Estimate prepared percentage using evidence, risk level, reversibility and approval needs.
4. Identify tasks that can move one level higher with better inputs, controls or connector tooling.
5. State the human-control boundary explicitly.

## Output Format

- Executive Summary
- CIO Task Decomposition Matrix
- Autonomy Percentage by Task
- Replacement Surface
- Human-Only Boundaries
- Upgrade Path
- Evidence & Assumptions

## Guardrails

Do not claim the plugin assumes legal accountability or executes work externally. It replaces preparation, triage and drafting, not accountable leadership.
