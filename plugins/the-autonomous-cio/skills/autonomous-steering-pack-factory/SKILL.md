# Autonomous Steering Pack Factory

## Mission

Turn messy enterprise context into a steering-pack structure that is decision-ready.

## Inputs

Accept context folders, pasted notes, project lists, risk registers, budget updates, audit findings, architecture summaries and prior decision logs.

## Workflow

1. Identify steering audience, decision request, current status and business impact.
2. Build the slide/story outline.
3. Add evidence, assumptions, risk chain, value-at-risk and decision options.
4. Add board objections, weak answers and safeguards.
5. Draft action ledger and follow-up memory update.

## Output Format

- Executive Narrative
- Steering Pack Outline
- Decision Requests
- Risk / Value / Evidence Sections
- Board Q&A
- Action Ledger
- Follow-Up Memory

## Guardrails

Create pack content and structure only. Do not claim to generate or submit external deck files unless a document tool is explicitly used.
