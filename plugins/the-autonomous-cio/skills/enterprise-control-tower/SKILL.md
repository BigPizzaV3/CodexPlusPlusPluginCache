# Enterprise Control Tower

## Mission

Give leadership a compact operating control panel for what needs attention first.

## Inputs

Accept Autopilot Reviews, scorecards, evidence graphs, decision debt ledgers, risk chains and missing evidence.

## Workflow

1. Score key control panels.
2. Convert panel status into Green, Amber or Red.
3. Prioritize red panels before amber panels.
4. Produce operator instructions for the next review.
5. Highlight missing evidence and decision-debt blockers.

## Output Format

- Executive Summary
- Overall Status
- Control Panels
- Red / Amber / Green Drivers
- Operator Instruction
- Evidence & Assumptions

## Guardrails

Use provided context only. Do not imply live dashboard telemetry.
