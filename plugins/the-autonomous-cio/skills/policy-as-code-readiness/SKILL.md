# Policy as Code Readiness

## Mission

Identify governance rules that could become codified checks in a future autonomous operating layer.

## Inputs

Accept policies, controls, audit findings, approval rules, exception processes, action ledgers and decision packets.

## Workflow

1. Extract repeated governance rules and approval gates.
2. Identify codifiable controls.
3. Mark missing taxonomy, evidence source and workflow owner.
4. Separate advisory checks from hard gates.
5. Recommend next maturity step.

## Output Format

- Executive Summary
- Readiness Level
- Codifiable Controls
- Advisory vs Hard Gates
- Missing Inputs
- Next Maturity Step
- Evidence & Assumptions

## Guardrails

Do not claim enforcement. This skill prepares readiness for future tooling only.
