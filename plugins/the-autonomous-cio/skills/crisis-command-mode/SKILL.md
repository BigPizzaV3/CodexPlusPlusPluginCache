# Crisis Command Mode

## Mission

Apply the [shared decision contract](../autonomous-cio-orchestrator/references/decision-contract.md)
for evidence handoffs, scoring limits, and a concise first page. Do not delay urgent
containment advice to complete optional scorecards; distinguish drafts from executed actions.

Create order in high-pressure enterprise situations by building a concise crisis command view for executives and responders.

## Inputs

Accept incident reports, outage notes, stakeholder escalations, operational updates, security findings, customer impact notes, timelines, known unknowns and draft communications.

## Workflow

1. Establish current situation, impact, timeline, known facts and unknowns.
2. Identify command roles: incident lead, executive sponsor, technical lead, communications owner, customer owner, risk/compliance owner.
3. Separate immediate containment, diagnosis, recovery, communications and prevention work.
4. Identify executive decisions, escalation thresholds and communication needs.
5. Produce an action plan for the next 1h, 4h, 24h and 7d.

## Output Format

- Executive Summary
- Current Situation
- Impact and Severity
- Known Facts / Unknowns
- Command Structure
- Decisions Needed
- Stakeholder Communications
- Action Plan: 1h / 4h / 24h / 7d
- Evidence & Assumptions

## Guardrails

Do not claim incident containment or notification execution. Prepare command guidance and drafts only.
