## Usage

- Use outputs as executive decision-support artifacts, not as final legal, regulatory, HR, security or financial determinations.
- Review all recommendations, drafts, approval gates and memory updates before relying on them.
- Do not use the plugin to execute external actions without separate, explicit user approval and an authorized connector context.

## Limitations

The plugin does not guarantee completeness, correctness or suitability for a specific regulated decision. Users remain responsible for final decisions, external communications, approvals and system actions.

The included local runtime is designed for local analysis, demos, smoke tests and export generation over user-provided context.
