## [1.0.0] - 2026-09-09

### Added

- Eight skills: `ship24-integration`, `ship24-webhooks`, `ship24-couriers`, `ship24-tracking-statuses`, `ship24-troubleshooting`, `ship24-node-sdk`, `ship24-track`, `ship24-webhook-test`.
- `ship24-integration-reviewer` agent for read-only audits of existing Ship24 integrations.
- Bundled configuration for the hosted Ship24 Tracking MCP server (`https://api.ship24.com/mcp`).
- Manifests for Claude Code, Cursor, OpenAI Codex, GitHub Copilot (Agent Plugins 1.0), Gemini CLI and the Vercel `skills` CLI.
