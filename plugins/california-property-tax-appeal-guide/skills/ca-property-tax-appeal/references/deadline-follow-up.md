# Deadline and follow-up schedule

Read this reference after the formal deadline is verified and again when an acknowledgment or hearing notice arrives.

Maintain every event in the case state's `deadlines` array with an exact date, status, source, verification date, responsible party, and next action. Separate statutory/county deadlines from suggested preparation reminders.

Track when applicable:

- formal application deadline;
- informal-review deadline;
- deficiency-correction deadline;
- fee or waiver deadline;
- exchange-of-information request and response dates;
- exhibit/witness submission deadline;
- hearing confirmation and hearing date;
- postponement, withdrawal, or stipulation response date;
- findings-of-fact request/payment deadline;
- refund/corrected-bill follow-up date;
- any officially verified further-review deadline.

Offer reminders only after the user asks for or accepts them. A reminder is convenience support and does not change the official deadline. Suggested reminder offsets are 30, 14, 7, 3, and 1 day before a deadline when time permits, but avoid excessive reminders and let the user choose. For a deadline within 3 days, lead with the immediate action rather than scheduling reminders.

Never create a reminder from an unverified date. If the county describes a relative deadline, such as a number of days after mailing, store the triggering date, rule, calculation, and source; ask for the actual triggering document date before calculating.
