# Content Matrix

## Inputs

Use 4 content pillars when available. If the user supplies fewer, work with what exists rather than inventing expertise.

Use 8 formats:
1. observation
2. how-to
3. contrarian take
4. case or example
5. mistake
6. framework
7. story
8. question or debate

## Output

Create a matrix with one concrete idea for every pillar-format pair.

Each idea should include:
- working angle
- why the reader cares
- proof or source needed
- suggested format/platform

Avoid 32 cosmetic variations of the same claim.

Finish by selecting the 5 ideas with the strongest mix of relevance, proof availability, and novelty.
