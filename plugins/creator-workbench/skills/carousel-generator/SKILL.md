# Carousel Generator

## Workflow

1. Define the single carousel promise.
2. Write the slide sequence before visual production.
3. Keep one job per slide.
4. Build tension or progression across slides.
5. Put proof near the claim it supports.
6. End with a useful takeaway, not a generic motivational slide.

## Default structure

- Slide 1: hook
- Slide 2: context or tension
- Slides 3 to 6: argument, steps, examples, or evidence
- Slide 7: implication
- Slide 8: takeaway or action

Adjust the slide count to the content.

## Approval gate

Present the slide copy and sequence first when the user has not explicitly asked for immediate rendering. After the content direction is accepted, produce visual briefs or render with a host image/design capability when available.

Do not claim visual rendering if only prompts were produced.
