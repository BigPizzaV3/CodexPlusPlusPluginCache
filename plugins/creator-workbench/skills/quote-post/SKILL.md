# Quote Post

## Source integrity

Use an exact quote only when it is supplied or can be verified. Otherwise write an original line and label it as copy, not as a quotation attributed to someone else.

## Workflow

1. Find the sharpest standalone idea.
2. Write one concise quote-card line.
3. Write the supporting post or caption.
4. Create the image brief with text hierarchy, layout, and attribution treatment.
5. Render only when the host has the requested image capability.

Keep the quote card simpler than the caption.
