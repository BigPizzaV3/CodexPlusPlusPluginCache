# DevRecap Terms of Use

_Last updated: September 14, 2026_

DevRecap is an open-source developer productivity tool that reconstructs work from sources the user explicitly authorizes and generates evidence-backed recaps.

## Use of DevRecap

You may use DevRecap for lawful purposes and only with development history, repositories, accounts, and data you are authorized to access. You are responsible for following your employer's, client's, repository owner's, and service provider's policies when using local development history or generated reports.

## Local data and generated reports

DevRecap may read local Codex history, Claude Code history, and read-only Git metadata only after explicit source authorization. It may create local configuration, structured analysis files, and HTML/PDF report artifacts as described in `PRIVACY.md`.

Generated reports are summaries derived from available evidence. They may be incomplete or contain interpretation errors. Users should review reports before relying on them for employment, compliance, billing, legal, security, or other high-impact decisions.

## No background monitoring

DevRecap is designed for explicit invocation. It does not provide continuous employee monitoring, background watchers, or automatic activity surveillance.
