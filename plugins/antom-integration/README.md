# Antom Integration

Antom Integration is a skills-only plugin for ChatGPT and Codex. It helps
developers choose an Antom payment product and integration mode, consult current
Antom documentation, generate or review integration code, troubleshoot API and
notification issues, test in Sandbox, and prepare for go-live.

It does not execute payments and does not require an MCP server.
