# Privacy

Conversational Narrative is a skills-only Plugin. The packaged Skills do not define an external server, database, analytics collector, or third-party app connection.

The Plugin itself does not independently collect, sell, or transmit user data. Content handling is governed by the ChatGPT, Codex, API, workspace, and account settings through which the Skills are used.

If a future version adds an external app or MCP service, this notice must be updated before release.
