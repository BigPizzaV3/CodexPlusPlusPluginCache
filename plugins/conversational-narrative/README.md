# Conversational Narrative

A skills-only ChatGPT/Codex Plugin for writing and refining technical practitioner deep-dives that sound like real reasoning rather than template content.

## Public Skills

- `conversational-narrative-router`
- `diagnostic-deep-dive-writer`
- `technical-concept-storyteller`
- `series-continuity-writer`
- `voice-fidelity-reviewer`

The Plugin does not require an external app or MCP server. It does not independently access accounts, repositories, or private data. Users can supply source material in the host product and the Skills operate on that available context.

## Design principle

The core writing movement is friction -> sharper question -> concept -> concrete evidence -> decision consequence -> next unresolved problem.

It intentionally avoids forcing every post into a visible marketing framework.
