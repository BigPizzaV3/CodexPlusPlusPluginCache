# Terms note

Marketing Swarm provides analytical workflows and recommendations. Outputs are not a guarantee of advertising performance and should be checked against the user's business context, platform policies, experiment design, and current account state.

The Plugin package does not itself authorize or execute campaign changes. Any external action requires a compatible host app, the user's permissions, and explicit authorization for the requested change.
