# Privacy note

Marketing Swarm is packaged as a Skills-only Plugin. The package itself does not run an external service, receive credentials, or store campaign data on a publisher-operated server.

Data handling depends on the ChatGPT/Codex host and any apps the user separately connects. Those apps keep their own permissions, authentication, retention, and privacy terms.

The Skills instruct the model not to expose secrets or copy credentials into reports, examples, manifests, or generated artifacts.
