# Support

The public customer-support channel is [GitHub Issues](https://github.com/tabutyn/build-3d-game-rooms/issues).
Use it for bug reports, feature requests, installation problems, privacy
questions, and security-conscious reports that do not contain secrets or
private assets.

Before filing, run the checks in `README.md` and include the plugin version,
operating system, Blender version when relevant, the failing command, and a
minimal sanitized evidence package. Never include API keys, credentials,
private assets, or unsanitized project data in a public issue.
