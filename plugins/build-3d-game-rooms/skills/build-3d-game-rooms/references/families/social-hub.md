# Social hub adapter

- Use for shops, lobbies, plazas, and exploration rooms with multiple destinations or points of interest.
- Establish a clear arrival, primary destination, secondary destinations, and return route.
- Preserve circulation clearance around queues, counters, kiosks, doors, and interactive clusters.
- Make storefronts, service points, and passages semantically honest; false doors and blocked arches fail Function.
