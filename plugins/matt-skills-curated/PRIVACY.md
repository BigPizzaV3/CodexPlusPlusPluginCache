# Privacy

Matt Skills Curated is a skills-only ChatGPT/Codex plugin. The plugin itself runs no remote service, stores no conversation history, and sends no telemetry.

A Skill may ask ChatGPT or Codex to use tools already available in the current session, such as repository, browser, issue-tracker, or terminal tools. Those tools remain governed by the host product, the connected service, the user's permissions, and the confirmation rules of the current session.

Do not place credentials, tokens, cookies, private keys, or other secrets in Skill files or plugin artifacts.
