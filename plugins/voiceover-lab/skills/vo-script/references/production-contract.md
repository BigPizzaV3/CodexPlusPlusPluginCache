# Production Contract

Rules for any skill that writes files.

- One project folder per job: `brief.md`, `voice-guide.md`, `cast.md`, `lexicon.md`, `scripts/`, `renders/`.
- Readable scripts and render-ready scripts are separate files. Render-ready files contain only text the engine should speak, plus supported inline tags.
- Never place the affiliate footer, markdown headings, links, or stage notes inside a render-ready file.
- Name files by section and version: `ch03-v2.txt`, `ad-30s-v1.txt`.
- Record the voice, model class, and settings used for every render in `cast.md`.
- Never claim audio was rendered unless a tool actually produced it.
