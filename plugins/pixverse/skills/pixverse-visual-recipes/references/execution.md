# Selected Treatments And Continuation

Browsing treatments does not generate media. Execute only the selected treatment
with its requested subject, medium, count and format. A quoted or explanatory name
is not an instruction to submit a job.

Read the chosen row in `./preset-images.md` or `./preset-motion.md`: the catalogs
contain 45 image and 18 product-motion recipes. Retain its composition/action,
reference roles, required starting plate, timing, output count and repair criteria.
The broader `./image-directions.md` and `./motion-directions.md` support free briefs.
Recipe names select creative instructions; they are not PixVerse model or API IDs.

For a new effect name, obtain enough visual detail to define the visible mechanism,
then author the prompt using the actual image/video modes. Do not infer hidden
parameters from a display name. Apply Sunburst 2K/high for stills and edits and
Seedance 2.5 1080p for video, subject to the shared quality policy.

Submit through the normal preflight path, save the returned task ID and resume that
task. Redisplaying a result never creates a second generation. Retain all returned
assets in caller order and distinguish submission, completion and file delivery.

When adding a treatment, preserve its concrete inputs, camera/light/material action,
start/end state and sound. Verify visible motion against the selected recipe.
Reference reuse and local edits follow `../../../skills-shared/extended-capabilities.md`.
