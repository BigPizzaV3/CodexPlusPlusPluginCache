# Generated Brand Applications

Read `./foundation.md` first. Use only the accepted brand slots needed by the output.
Preserve supplied copy and claims. Deliver generated PNG/JPG images at the requested
aspect, with the source references and prompt recorded for later edits.

## Mockups And Image Edits

Choose a credible object and a specific art-directed idea. Lock surface, placement,
logo scale, clear space, material color and printing/embossing behavior. Declare
which reference controls the scene, official artwork, product and typography.

Use Sunburst 2K/high for both new scenes and image edits. Reuse a supplied or accepted
scene directly. When a new text-bearing mockup needs separate control, first generate
the scene with a blank application surface, then edit it using the scene first and
approved artwork second. Keep the same aspect; the second stage changes only the
intended artwork/lettering, preserving camera, people, folds, environment and light.
Count both jobs in the plan when both are required.

Full-color print, monochrome ink, foil, embossing and engraving need the correct
approved mark variant and plausible physical behavior. Retain perspective, folds,
grain, occlusion, reflections and real print edges. Do not let the scene invent a
new logo, recolor an accepted mark or add unsupported product claims.

For comparison sets reuse the same subject, scene, camera, material and light.
Change only the requested application or colorway. Avoid arbitrary props, floating
print, pseudo-copy and a generic glossy finish on every material.

## Image Families

| Image output | Inputs and visual checks |
|---|---|
| Packaging mockup | Actual package type, supplied dimensions, material, exact product name and approved artwork; credible folds and label placement |
| Merchandise visual | Item, print area, fabric color, method and selected variant; preserve scale, folds and image identity |
| Signage concept | Supplied setting, sign proportions, lighting and exact copy; readable placement and plausible mounting |
| Poster/banner | Headline/body/CTA, aspect and brand references; clear hierarchy, margins and legible lettering |
| Social graphic | Square, 4:5, 9:16 or channel banner; exact copy or no text, platform-safe placement |
| Carousel | Ordered cover/body/CTA images; one hierarchy, palette and image treatment across the set |
| Brand guide images | Accepted mark, palette, typography direction and examples; coherent visual pages with a fixed count |

These are image deliverables. Exact manufacturer specifications and supplied artwork
remain their original sources; a generated mockup does not replace them.

## Brand Guide Images

Preserve a supplied visual template. Plan the guide from accepted content:

1. Cover with the exact brand name.
2. Concept and palette rationale using accepted copy.
3. Canonical logo shown from its authoritative reference.
4. Only approved logo variants; omit empty slots.
5. Palette with recorded hex/RGB labels and their intended roles.
6. Typography direction or a supplied specimen, clearly distinguished from verified font output.
7. Accepted mockups, normally two examples per image; use one slot when only one exists.

Keep names, marks and mockups proportional. Reuse the selected layout and typography
direction across pages. Deliver the actual image set and a concise text record of
palette values, copy and selected references. A generated swatch/letterform is still
subject to pixel-level variation; do not claim exact reproduction without evidence.

## Revision

Check requested copy, dimensions, layout, physical application and the selected brand
revision on actual images. For a local correction, use the accepted image as the edit
reference and state precisely which region/content changes. Preserve successful set
members and record the latest accepted file. Do not regenerate the full set for a
single defective application.
