# Brand Visual Foundation And Revision State

Use this for new visual identities, partial kits and application of supplied branding.
The image recipes in `./applications.md` consume only the decisions they need.

## Route By What Is Needed

- **Apply existing:** record official assets as authoritative; preserve their spelling,
  shape, colors and letterforms. Do not redesign a supplied identity.
- **Extend partial:** create only missing choices used by the requested output.
- **Explore a new identity:** derive palette, three distinct logo mechanisms and a
  typography direction. Explicit choices or delegated selection take precedence.

| Requested image output | Required foundation |
|---|---|
| Logo concept | Name/meaning, palette and selected symbol mechanism |
| Palette board | Requested palette direction and existing context |
| Copy-free mockup | Supplied/selected logo; palette when its colors are used |
| Social graphic, package, sign or poster | Logo, palette, exact copy and typography direction |
| Brand guide images | Accepted mark, palette, typography and example images |

## Durable Brand Record

Store one local record with revisioned slots and authoritative image paths/provider
IDs. Each slot is fixed, proposed, unknown or not_applicable. Record whether a value
came from supplied facts, measurements, visual observation or creative inference.
Agent quality assessment alone is not user acceptance; explicit delegated choices
can be recorded and used within that authorization.

Record exact name, offering, audience, concept, selected logo images/variants,
hex colors and their roles, type references, layout/spacing, motifs, image treatment,
avoid rules, output count, dimensions and copy. Load only the needed slots. Each
application's prompt receives the same compact lock: exact spelling, reference roles,
palette/type roles, layout, motif, invariants and requested changes.

## New Visual Identity Sequence

1. Derive one expressive premise from product truth, audience, name/letter cues and
   reference forms. Quiet elements support it; avoid generic luxury/premium styling.
2. **Palette:** normally compare three options, with 3–6 named colors each, background,
   text and accent roles, readable pairings and a brief-specific rationale. Options
   differ in intent, not only hue. Record exact intended hex values separately from
   their generated presentation. Palette-only work does not add a logo prematurely.
3. **Symbol:** develop three distinct mechanisms, such as a name-derived monogram,
   product/process pictorial idea and benefit/relationship abstract idea. A mascot or
   emblem can fit the brief. Each needs a specific silhouette, negative-space device,
   construction or color relationship; three minor shape variations are insufficient.
4. Generate each candidate with Sunburst 2K/high as a separate image. Use one concept
   per candidate, simple legible geometry and the selected palette. Keep the prompt,
   provider ID, image and selection state. Preserve authoritative supplied marks.
5. **Typography direction:** show 2–3 distinct pairings or lettering directions with
   actual brand name and a short accepted sample. Use the selected mark and supplied
   font specimens when available. One family is valid when appropriate; normally use
   at most two. Treat generated lettering as a visual proposal, not proof of an exact
   font. Preserve the chosen reference in later image edits.
6. Inspect the selected images together for coherent concept, legibility, contrast,
   silhouette and consistent roles. Continue the requested applications when their
   needed decisions are resolved; a combined board is not another approval gate.

## Logo Prompt Contract

Specify mark type → one central mechanism → construction/negative space → visual
style → color roles → centered composition → small-size readability. Keep one clear
concept per candidate. Symbol-only prompts have no name/tagline except explicitly
chosen monogram initials; use “no additional text” to preserve that exception.

Flat fills, monoline, a restrained gradient or hand-drawn strokes are possible visual
styles. State stroke/fill behavior, symmetry and detail limits. Use 1–3 mark colors
when helpful, without padding to a quota. Preserve the requested formal style.
Avoid automatic leaf, shield, sparkle, globe or gold-serif substitutions without a
brief-specific reason. A dimensional/mockup presentation is a separate application.

## Selective Revisions

- A palette change updates dependent generated concepts/applications; an official logo
  remains fixed unless the user changes it.
- A symbol change updates its applications and triggers a typography coherence check.
- A type change affects wordmarks and text-bearing images, not unrelated symbol art.
- Keep exact slot revisions with each output. Remove superseded images from the active
  set and repair only affected items using Sunburst with the accepted image reference.

Deliver the selected image files, source references and concise palette/copy record.
Inspect actual generated text, color appearance and proportions. Do not infer exact
pixel or lettering fidelity solely from what the prompt requested.
