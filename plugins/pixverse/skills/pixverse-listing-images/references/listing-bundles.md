# Listing Bundles And Evidence

Choose the requested image bundle and preserve its count and module purposes. For a
named market/category, use current official marketplace rules when submission compliance
is requested. A generic image prompt alone cannot establish compliance.

| Requested scope | Ordered outputs | Count |
| --- | --- | --- |
| Main | Main product image | 1 |
| Product images | Main + infographic, multi-angle, detail, lifestyle, what's in box | 6 |
| A+ | Main + hero, pain points, features, ingredients/materials, efficacy/evidence, how-to, endorsement | 8 |
| Full set | Main + five secondary images + seven A+ modules | 13 |

An explicit custom subset uses only its named assets. A completed accepted main image
is reused as the identity anchor instead of regenerated. A+ ingredient,
efficacy and endorsement names do not authorize false claims: resolve supported material,
measured evidence and actual endorsement; adapt the module's purpose or identify missing
input when inapplicable. Never invent an authority seal, review, ingredient or guarantee.

Inspect the product, brand context, category, target marketplace and desired visual system.
Main image is an identification asset under that marketplace's actual rules. Secondary
cards explain a single buying question each. A+ modules develop one longer brand/product
argument with shared palette, typography, spacing and exact product appearance.

Prepare a module table with purpose, evidence/source, literal copy/units, product views,
layout, aspect and platform constraints. Choose justified imagery and precise editable
labels/arrows. Keep comparison scales equal and dimensions/units traceable. Do not infer
unseen box contents from a generic category. Render text deterministically when exactness
matters; image prompts carry the required composition, not invented specification text.

Check the named marketplace's main/secondary/A+ restrictions separately, including image
content, size, text/promotional restrictions and claims where applicable. Use current
official evidence before a compliance claim. A draft with unavailable rules is labeled a
draft, not submission-ready. Deliver all ordered images and any FFmpeg overlay sources,
preserving passing modules when only one fact or label changes.
