# Causal Explainer / Education

Apply `./genre-routing.md`. Define one central question with tension, the audience's reasonable
misconception, a concrete anchor and personality/VO/inquiry lane. Viewer is the protagonist:
their decision, body, object or experiment carries the mechanism. Three≤30s hooks each
show a concrete image and open the question: artifact, misconception flip, what-if,
impossible object, real in-progress experiment, sourced event or demonstrable challenge.

Long form: after hook, stakes plus ideally three ordered questions around0:30–1:30;
minimum mechanism/anchor12–30%; escalating applications30–70%; earned reversal60–75%;
meaning/zoom-out85–95%; optional one-line next question. Facts may peak around70%, meaning
at the end. Personality lane follows real attempts/test/payoff; inquiry follows evidence
discovery; VO advances one causal link/paragraph. A fake conclusion can be overturned only
when it actually teaches the misconception, not as an arbitrary suspense trick.

Abstract concept requires the analogy sequence: flag the analogy → run the physical
object's own logic for2–4sentences without jargon → return with the technical term → reuse
as shorthand → state where it breaks. Every big number gets a household scale comparison.
Show before naming; define a term immediately with a concrete image. Stage a real available
test when it proves the claim. Do not invent experiment results.

Use second person, present tense and spoken phrasing; a growing explanation lands on a
short3–6word realization. No>~30s abstraction without a physical anchor and no90s stretch
without information payoff/reversal/delight. A “but” changes the mechanism/stakes, not
just the wording. Track promised answers within the same act; no false callbacks, lecture
openings, definition-first throat clearing or unearned moral before the mechanism.
State uncertainty where the evidence requires it; hook confidence never overrides truth.

At≤4min: one question, one analogy, one turn. Hook0–10%, anchor/mechanism10–60%, turn
60–85%, payoff and one-sentence zoom-out. No three-question contract, IOU stack or fake
ending; one loop paid at the end. Around420–470words/3min,15–30s timestamps,3–5retention
rows. Vertical establishes the concrete image in first2s. Deliver three hooks, full
spoken body with explanatory visual/demo cues and the actual question/payoff map.
