# Reuse Matrix

| Change | Regenerate | Reuse | Re-render locally |
|---|---|---|---|
| Host or presenter | host image, every speaking take of that host, holding views | script, B-roll, music, board icons, plan | stickers/lower-thirds carrying the host's name or face |
| Product | product stills, holding views, product inserts; takes only if the product is on camera | host, voice, music, captions | board icons, labels with the product name |
| Wording (same language) | takes for the changed segments | everything else | captions, any label with changed text |
| Language | voice reference in the new language, all takes | host image, B-roll, board, music | captions (new font/grouping), labels, stickers |
| Hook only | the hook segment's take | body takes, everything else | none |
| Aspect | usually nothing; new takes only when the framing must change | all assets | plan geometry, graphics canvas size |
| Tone or style | takes (performance) and possibly host image | script, music unless tone changes it | caption style |

## Naming

Keep the base project slug and add a suffix per variant (`<slug>-cat`, `<slug>-es`,
`<slug>-hook-2`). Each variant project has its own queue, timeline and plan; reused tasks
point back to the base manifest.

## Cost discipline

- Never reuse a take whose words changed; align and check before assuming.
- A retake for one variant does not touch the others.
- Report reused tasks as reused (zero charge) and generated tasks with their ledger credits.
