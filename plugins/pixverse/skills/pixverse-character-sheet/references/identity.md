# Character Reference Continuity

Use character sheets and accepted reference images to keep people, characters and
props consistent across generated shots. Reuse the accepted source rather than
creating a replacement face. Lock face proportions, hair, silhouette, wardrobe,
body/prop scale and supported views. Treat unseen rear geometry as a creative
extension unless the user supplies that view.

Keep identity, expression, outfit and scene references distinct. A lineup or
turnaround guides the sequence; it is not the literal opening frame of a single
photograph. Select only the needed views and keep them readable at output size.
For supplied people, retain their visible appearance without inventing personal
attributes. One good reference can support a simple shot; do not impose a fixed
photo collection on ordinary image generation.

Generate or refine references with Sunburst 2K/high. Save selected image paths,
provider IDs and the accepted continuity notes. In each later image/video job,
map those references to supported inputs and state what each controls. Review
requested continuity checks on actual output; a prompt alone does not prove that
all features were preserved.
