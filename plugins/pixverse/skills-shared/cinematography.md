# Cinematography Notes

Use these as vocabulary, not decoration.

## Camera

- locked-off product macro
- slow push-in
- handheld phone-native drift
- lateral tracking
- orbit reveal
- overhead table rig
- close-up insert
- rack focus
- whip pan only when energy fits
- transition by match cut, occlusion, or light flare

## Light

- soft window side light
- tungsten practicals
- overcast daylight
- sodium vapor street light
- neon reflection on wet surfaces
- top-lit product table
- edge rim light
- low-key contrast
- high-key clean commerce light

## Composition

- negative space for copy
- center-weighted hero product
- foreground occlusion
- layered depth
- symmetrical luxury
- phone-native imperfect framing
- UI safe zones

## Motion Discipline

One shot can only do so much. Prefer one subject action plus one camera action. Too many simultaneous changes create mush.
