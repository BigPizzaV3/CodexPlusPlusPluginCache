# Exploration Patterns

Use local agent budget to explore before spending video credits.

## Territory Board

Generate 3-4 still image directions with different strategic intents:

- premium safe
- memorable strange
- social-native direct
- cinematic/emotional

Then pick based on the user's original goal, not just prettiness.

## Reference Remix

When the user provides a reference video:

1. Extract pacing, structure, visual grammar, hook, and emotional promise.
2. State what will be kept and what will change.
3. Generate a new concept that is structurally related, not copied.
4. For a full rebuild with a new person, product or language, use
   `../skills/pixverse-video-remake/SKILL.md`; it keeps the timing relationships
   (what each graphic answers) rather than the seconds.

## One Strong Sample

For expensive or uncertain work:

1. Generate one representative board or clip.
2. QA it.
3. Continue only if it proves the route.

## Variant Ladder

For ads:

- Hook-first performance variant.
- Brand-film premium variant.
- Demo/benefit clarity variant.
- Weird thumb-stopping variant.

For narrative:

- quiet emotional variant.
- kinetic genre variant.
- surreal symbolic variant.
- dialogue-driven variant.
