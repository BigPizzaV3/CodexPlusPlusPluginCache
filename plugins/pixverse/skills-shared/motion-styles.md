# Episode Motion Directions

Use Auto when style choice is delegated, the selected named direction when supplied,
or the user's custom references. Otherwise resolve that material choice once. Auto
authors a direction from content, audience and footage; it need not pick a preset.
These are recognizable grammars, not mandatory palettes, templates or event quotas.

| Direction | Composition and information | Motion and useful starting values | Avoid |
| --- | --- | --- | --- |
| Bold Editorial | Large sans claims, asymmetric image/type fields, neutral plus one accent, shared supporting edge | 180–350ms firm reveals, 400–650ms larger reorganizations; masks expose contrast; retain a key word/edge across scenes | Repeated poster resets, equal emphasis, micro-copy as texture |
| Funky Modular | Bold readable modules, meaningful duotone/triad, plain/pattern contrast and visible gaps | Sort, regroup, make room and hand off; 250–500ms moves, optional 2–4% focal overshoot, 60–110ms stagger; final layout rests | Sticker clutter, everything wobbling, unmotivated elasticity |
| Luminous Interface | Legible nodes/rows, restrained luminous depth, values tied to real states | Input→connector→output causality; local changes 180–350ms, reflow 350–650ms, cause leads effect 80–160ms; coupled values finish together | Fake dashboards/statistics, constant scanning, decorative glass |
| Documentary Collage | Authentic source anchor, source/annotation distinction, quiet paper or monochrome with signal color | Place→connect→isolate→resolve; 300–600ms placements, 60–140ms offsets, 250–500ms annotations; preserve source context | Fabricated evidence, illegible aged pages, chaotic scrapbook |
| Web Brutalism | Heavy condensed type plus functional mono, exposed hard grid, extreme hierarchy, ground/ink/alarm accent | Instant or 80–160ms snaps, 180–350ms hard masks; long still holds; optional coupled 6–8Hz steps; brief corruption only for an actual interruption | Elastic bounce, habitual glitches, face-obscuring threshold/inversion |
| Minimal | One dominant object/phrase, deliberate open space, neutral sans and clear hierarchy | Transform in place, make room, transfer attention; 350–650ms spatial moves, 1–3% travel, 150–300ms handoffs; 1–2s or longer readable hold | Generic fades per object, thin unreadable type, idle ambient loops |
| Press | One hard margin, heavy display against mono, flat screened objects with real figure captions | Switch-like arrival and dead-still holds; rules expose rows, one stepped value or specification strip; coupled channels share cadence | Soft gloss/shadow, fake metadata; never apply print grain or stepped time to a speaking person |
| Editorial Overlay | Host owns frame; serif claims and quiet functional sans dock in actual emptiness; one small accent, soft plates only where needed | Short upward arrival with long settle, faster exit, overlapping group entrance; baseline swaps and proportional extraction; host alone moves during holds | Scaling from nothing, rotation, bouncy snaps, full-frame scrims or crossing face/hands |

Values are starting points, not a pace imposed on the spoken performance. A quiet graphics
hold does not authorize slowed host speech. Each treatment needs entry, a complete readable
state and an exit/continuation. Related ranks, comparisons and timelines develop persistent
information instead of restarting a component with new copy.

Standalone type is valid in every direction; containers, pictures, textures and icons need
a purpose. Preserve the selected supporting-media plan; a style cannot replace real evidence
with decorative cards. Translate references to authored palette, fonts, spacing, image use
and motion; never copy unrelated logos, source copy or fabricated figures. Adapt to actual
camera geometry, safe zones, measured phrase times and the FFmpeg edit.
